GateShala is a free website for students preparing for **GATE Computer Science and Information Technology (CS/IT)** and for anyone learning to program.

## What you will find here

- **All 12 GATE CS subjects**: Engineering Mathematics, Discrete Mathematics, Digital Logic, Computer Organization and Architecture, Programming and Data Structures, Algorithms, Theory of Computation, Compiler Design, Operating Systems, Databases, Computer Networks and General Aptitude.
- **Subject-wise notes** that explain each topic step by step, with figures and worked examples.
- **GATE-style practice questions** at the end of lessons, each with an answer and a full explanation.
- **Programming tutorials** for Python, C, Java and JavaScript, plus Data Structures and Algorithms.
- **An online playground** where you can write and run code in the browser.

## How the content is checked

Every code example on the site is run with the real compiler or interpreter before the site is published, and the output shown on the page must match exactly. Numerical answers to practice questions are recomputed by a program. If something still looks wrong, please tell us through the [contact page](contact.html).

## About the questions

The practice questions on GateShala are original questions written in the style of the GATE exam. They are not copied from past GATE papers. GATE is conducted by the IITs and IISc; GateShala is an independent website and is not connected with them.

## Free to use

All lessons are free to read. No account or sign-up is needed.
